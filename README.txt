ABOUT PIXELSCAN:
----------------
PixelScan is a high-performance Windows desktop application designed to scan,
compress, reconstruct, and optimize digital images with 100% lossless fidelity
and advanced binary reduction engines.

No Python installation is required to run this standalone application.


QUICK START:
------------
1. Extract the downloaded ZIP archive into any folder on your computer.
2. Double-click "PixelScan_PyInstaller.exe" (or "PixelScan.exe") to launch.
3. Choose your desired tool from the top navigation tabs:
   - [⚡ Compress Image]     : Scan & compress images into .icomp packages.
   - [🔄 Decompress Image]   : Restore images from .icomp files.
   - [🔍 Lossless Verifier]  : Verify 100% pixel-for-pixel accuracy.
   - [⚡ Direct Formatter]   : 1-click optimize to WebP, JPEG, or PNG.


SYSTEM REQUIREMENTS:
--------------------
- Operating System : Windows 10 or Windows 11 (64-bit)
- RAM              : 2 GB minimum (4 GB+ recommended for large 4K+ images)
- Disk Space       : ~60 MB free space


OUTPUT DIRECTORY:
-----------------
All compressed packages (.icomp), text strings (.txt), reconstructed images,
and formatted outputs are automatically saved to the "output" folder located
in the application directory. You can easily access this folder anytime by
clicking the "📁 Open Output Folder" button in the app.
